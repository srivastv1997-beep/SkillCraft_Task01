# House Price Data Analysis and Visualization

## Project Overview

This project analyzes the King County House Sales dataset using Python. The goal is to explore the dataset, identify relationships between features, and visualize important patterns using data analysis techniques.

## Dataset

* Dataset: King County House Sales Dataset
* Records: 21,613
* Features: 21

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Project Tasks

1. Load and inspect the dataset.
2. Check for missing values.
3. Generate a correlation heatmap.
4. Create a histogram of house prices.
5. Analyze relationships between variables.

## Visualizations

### Correlation Heatmap

The heatmap helps identify relationships between numerical features and house prices.

### House Price Distribution

The histogram shows the distribution of house prices in the dataset.

## Key Findings

* No missing values were found in the dataset.
* House prices are strongly correlated with:

  * sqft_living
  * grade
  * bathrooms
* The price distribution is right-skewed, indicating that most houses are moderately priced while a smaller number are highly expensive.
